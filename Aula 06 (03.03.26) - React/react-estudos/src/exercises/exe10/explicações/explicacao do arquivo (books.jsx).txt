Arquivo books.jsx

1) Aqui atribuimos a variável "books" um array, que é uma lista de dados, um conjunto de dados, que podem ser de tipos diferentes.
* Uma lista ordenada de valore

2) Dentro desse array colocamos vários objetos, OBS: Não sei explicar o que é objeto.
* Um objeto é uma estrutura queguarda informações organizadas em pares (chave: valor)
* Então objeto = conjunto de propriedades

3) No final exportamos essa variável para ser reutilizada em outras partes do código
* Outros arquivos podem importar

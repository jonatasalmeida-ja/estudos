Próximo arquivo é o BooksItem.jsx
import { useState } from "react";
import Button from "./Button";

function BooksItem({ title, author }) {
    const [showBook, setShowBook] = useState(false);

    function toggleSwitch() {
        setShowBook(prev => !prev);
    }

    return (
        <div>
            <p>{title}</p>

            <Button 
                label='Ver autor'
                onClick={toggleSwitch}
            />

            {showBook && (
                <p>Autor: {author}</p>
            )}
        </div>
    );
};

export default BooksItem;

O que é um useState:
É um Hook do React.
Hook é uma função especial do React que permite usar recursos do React
Nesse caso: useState permite crirar estado dentro de um componente

Estado é uma informação que pode mudar e que afeta a interface
No caso: Mostrar autor? sim ou não

const [showBook, setShowBook] é desestruturação de array:
showBook = valor atual
setShowBooks = funçao para mudar o valor

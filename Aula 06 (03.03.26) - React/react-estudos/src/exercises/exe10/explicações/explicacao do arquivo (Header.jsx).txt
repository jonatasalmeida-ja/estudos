function Header({ title }) {
    return (
        <h1>{title}</h1>
    );
};

export default Header;

retornar em html um "título h1" nomeado de acordo com a entrada enviada
OBS: Nesse pronto - Isso não é exatamente HTML, é JSX. JSX éHTML dentro do Javascript
Então o correto seria: criar um elemento h1 e mostrar dentro dele o valor de title.
